## 1. 一句话说明

这是航线模块里的**空域管理**页：把电子围栏、限飞区、备降点先记在账本上，再画到地图上，并同步到机场侧。

运营或航线配置人员进页后，先在「空域列表」筛、删、批量同步；需要画图或改形状时切到「空域配置」。菜单、路由 path 由后台动态下发，本页入口组件名为 `AirwayAirspace`；**未在代码中确认**中文菜单标题。

## 2. 代码地图

## 3. 页面长什么样、能做什么

顶栏两个 Tab：**空域列表**（默认）和**空域配置**。没有 `lazy`，两个房间都会挂上，只是一次只看见一个。

### 空域列表（账本）

- **看见**：搜索（变电站、机场、类型、状态）+ 表格（变电站/机场/无人机/名称/类型/同步状态/操作人/更新时间）+ 表头「批量同步」。
- **筛**：变电站清空后机场禁用并清空；选变电站才拉机场。改条件会自动查（`autoSearch`）。
- **勾选行 → 批量同步**：没勾选会提示；有权限才显示按钮。同步后清勾选并刷新。
- **行内编辑**：记下这条的 id、变电站、机场，切到配置 Tab。
- **行内删除**：确认后调删除接口，成功才刷新。

### 空域配置（工地）

左侧是目录，右侧是地图。

- **未打开表单**：筛变电站（进页默认第一条）、机场（可清空=全部）、类型、状态；列表点行或「定位」会飞到该图形；「新增」下拉：电子围栏 / 限飞区 / 备降点（围栏、备降点每种工作区最多一个）。
- **打开表单**：左侧换成名称、只读类型/站点、坐标文本；备降点多一项「备降转移高」。新增可开始/结束绘制；编辑可开关「编辑顶点」或「编辑点位」。保存/取消。
- **地图**：已有图形按图层开关显示；机巢蓝点；绘制时右侧出现撤销/重做/清空/完成；底栏显示鼠标 WGS84 经纬度。

### 权限（按钮级）

`query` 码在常量里有，**本页没有用它控显隐**。实际控按钮的是：列表编辑/删除/同步，配置新增/侧栏编辑删除/表单保存。

## 4. 页面流程（用户视角）

1. **进页**：落在空域列表；表格立刻请求 `/api/airspace/paging`。配置房间同时挂载：拉变电站 → 默认第一站 → 拉机场 → 拉工作区 `/api/airspace/workspace`。
2. **只查账本**：填搜索、翻页、勾选同步或删除。操作人列会尝试国密解密后再展示。
3. **从账本去改一条**：点编辑 → 切到配置 → 工作区按该站/机场加载并高亮 → 拉详情填表 → 左侧进入表单模式。
4. **在工地新增**：必须先选变电站和机场。选类型后进入绘制：围栏/限飞至少 3 点，备降点 1 点。保存走 create，成功关表单、刷新工作区，并通知列表刷新。
5. **在工地改形状**：编辑后默认进入顶点编辑（面）或点位编辑（备降点）。保存走 update。取消或切回列表时，若父页认为「正在编辑」，会先问「尚未保存，确认离开吗？」。
6. **带 query 跳入**：入口**没有读** `route.query`，不能靠 URL 定位某一条。

## 5. 页面逻辑（代码视角）

**谁改谁读**

- 父页：`activeTab`、`editContext`、`isEditing`、`discardToken`。
- 配置子页：自己的 `stationCode` / `dockSn` / 筛选，和列表搜索**不是同一份状态**。
- `isEditing` 只听子页 `editing-change`：打开新增/编辑为 true，保存或点取消确认为 false。切 Tab 丢弃草稿时父页自己把 `isEditing` 置 false，再加 `discardToken` 让子页关表单。

**类型怎么分流**

- `AirspaceType`：1 电子围栏、2 限飞区、3 备降点。
- 面：多边形 + 可拖顶点；点：Marker，单击地图换点。
- 工作区 `hasFence` / `hasAlternate` 禁用对应「新增」。

**坐标**

- 接口与表单是 WGS84 `[经度, 纬度]`。
- 上图、点击回写都经 `wgs84ToBd09` / `bd09ToWgs84`，再保留 6 位小数。

**父子通信**

- props：`editContext`、`discardToken`。
- emit：`edit-consumed`（父把 context 清掉，避免 watch 反复进编辑）、`editing-change`、`saved`（列表 `refreshData`）。

## 7. 坑点（已存在的别扭实现）

- **`src/views/airway/airspace/modules/airspace-config.vue`**：`onMounted` 里 `loadStations` 会写入默认 `stationCode`，`watch(stationCode)` 又会 `loadDocks` + `loadWorkspace`，挂载函数自己再调一遍，进配置房间容易连打两次工作区。
- **`src/views/airway/airspace/index.vue` 与 `airspace-config.vue`**：列表搜索和配置筛选各管各的；从列表带过去的站/机场只发生在点了「编辑」时。

- **`cancelForm`**：只要点返回/取消就弹「尚未保存」，不管有没有改过字段。
- **侧栏类型图标**用 `item.type === 1/2` 魔法数，和枚举文件可能日后对不齐：

## 8. 风险点（改这里容易出事故）

- **改坐标转换或省略转换**（`coordinate-adapter.ts`、`toAirspaceCoordinate`、`handlePolygonEdited`）：落库点会偏，设备按 WGS84 飞会错位。
- **改空间校验或保存时的 `closePolygon(...).slice(0, -1)`**（`airspace-config.vue` 的 `save`）：环多一个闭合点或少一个点，后端校验和地图回显都会炸。
- **改 220ms / 12 像素顶点判定**：顶点编辑会误删或双击变成两次单击。
- **父页 `isEditing` 与子页表单不同步**：未保存拦截失效，或永远切不走 Tab。
- **`editContext` watch 与 `stationCode` watch 打架**：从列表跳编辑时先改站再改机场，中间可能先按旧机场拉一次工作区，再被详情覆盖；乱加 `await` 顺序容易进错站。
- **权限漏判**：保存按钮只看 `airspace:save`，列表编辑看 `update`；只改一处会出现「能画不能存」或相反。
- **图层 `layerVisible.all` 为 false 时全部不画**：定位逻辑会强制把对应图层打开，但若有人改 `focusItem` 忘开图层，会以为数据丢了。

## 合上书自测

1. 用户在列表点某一行的「编辑」之后，配置页凭什么知道该打开哪条、哪个变电站和机场？
2. 正在画电子围栏时切回「空域列表」，什么条件下会弹确认？确认之后草稿怎么被清掉？
3. 保存备降点时，前端除了「至少一个点」之外，还会用工作区里的哪些图形做空间检查？

## 合上书自测答案

1. **靠父页塞过去的三件套。** 列表点「编辑」时，`index.vue` 把该行的 `id`、`stationCode`、`dockSn` 写进 `editContext`，再切到配置 Tab。配置页 `watch` 到这份 context 后：先切变电站/机场 → 拉工作区并高亮 → 再按 `id` 拉详情开表单；用完发 `edit-consumed`，父页把 context 清掉。

2. **条件：当前在配置 Tab，且子页通过 `editing-change` 把父页 `isEditing` 设成了 true**（打开新增/编辑都会发）。确认离开后：父页清 `editContext`、把 `isEditing` 置 false，并让 `discardToken` 加 1；配置页监听到 token 变化后关表单、关掉绘制/顶点编辑态，并 `history.reset()` 清空草稿。

3. **看工作区里的电子围栏和限飞区。** 备降点保存时：若已有电子围栏，点必须落在围栏内；若有任意限飞区，点不得落在任一限飞区内。机巢坐标也会参与「围栏包住机巢」这类校验，但那是改电子围栏时的规则；备降点这条主要盯围栏 + 限飞区。

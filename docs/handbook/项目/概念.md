# 概念
# 主辅联动

> 适用系统：区域型变电站远程智能巡视系统（区域层 / 边缘 / 单站）  
> 梳理范围：前端仓库业务概念、页面、接口、实时推送与任务落地  
> 说明：代码中明确出现「反向联动」；「正向联动」为电力主辅监控与巡视系统对接的标准叫法，对应本系统「信号触发 → 生成主辅联动任务」链路。

## 概念定义

### 主设备与辅设备

| 对象 | 电力业务含义 | 在本系统中的对应 |
| --- | --- | --- |
| **主设备** | 一次设备：主变、断路器、隔离开关、GIS、母线、套管等，由站内监控（SCADA / 综自）采集遥测、遥信、遥控 | 联动配置里的信号设备；设备台账树中 `deviceLevel = 2` 标记为「主设备」 |
| **辅设备** | 辅助/二次系统：消防、安防、暖通、照明、直流、在线监测（SF6、避雷器、局放等）、环境量 | 「主辅设备监控系统」接入的辅控/在线监测测点；首页「主辅接入」统计对象 |
| **主辅设备监控系统** | 主设备 SCADA 与辅控/在线监测的统称，对外以监控索引号标识测点 | 信号来源枚举值为「主辅设备监控系统」；信号类型为遥测 / 遥信 / 遥控 |

四遥约定（本系统 `signalType`）：

| 值 | 名称 | 含义 | 与联动的关系 |
| --- | --- | --- | --- |
| 1 | 遥信 | 开关量状态（分合、告警、变位） | 最常见的正向联动触发源 |
| 2 | 遥测 | 模拟量（温度、电流、压力等） | 越限/变化可触发联动 |
| 0 | 遥控 | 远方控制指令 | 可配置「结束信号」；一键顺控场景会带出监控索引号与联动信号 |

### 主辅联动（标准业务含义）

**主辅联动**指：主辅设备监控系统与智能巡视系统之间，按预先配置的「监控测点 ↔ 巡视点位 / 摄像机」关系，在信号变化或巡视结果产生时互相驱动。

完整闭环：

```
主辅监控系统（SCADA / 辅控 / 在线监测）
        │  正向：遥信变位 / 遥测越限 / 遥控下发
        ▼
  巡视系统按联动配置启动摄像机 / 机器人 / 无人机巡视
        │  反向：识别结果 / 告警 / 状态回写
        ▼
主辅监控系统接收反向联动文件，刷新画面或告警
```

业务目的：一次设备动作或异常时，巡视终端自动对准相关点位取证；巡视发现的缺陷/告警再回传到主辅监控，形成「看得见、回得去」的闭环。

### 正向联动与反向联动

| 维度 | 正向联动 | 反向联动 |
| --- | --- | --- |
| **触发方向** | 主辅监控 → 巡视系统 | 巡视系统 → 主辅监控 |
| **触发条件** | 已启用的联动配置对应测点发生遥信/遥测/遥控变化 | 运维人员在联动配置页选择记录，生成并下发反向联动文件 |
| **系统动作** | 按配置点位启动巡视（多终端策略），生成名称含「主辅联动任务」的计划 | 调用 `GenerateReturnlinkageFile` 生成回传文件；指令类型来自字典 `GenerateLinkageCommandConfig` |
| **前端可见结果** | 任务管理出现联动任务；右上角「智能联动」通知（9_6）；首页「智能联动记录」新增行；联动配置表「属性 / 值描述 / 事件时标」实时刷新（9_5） | 提示「反向联动文件生成成功」；区域层可将配置文件下发到边缘 |
| **代码用词** | 未出现「正向联动」四字，由联动配置 + 主辅联动任务 + WebSocket `9_5`/`9_6` 实现 | 按钮文案与接口注释均为「反向」 |

**业务差异：**正向解决「设备动了要不要去看」；反向解决「看成什么样要不要告诉监控」。正向是自动、实时、任务级；反向是文件级、人工触发、面向主辅监控侧。

### 主辅联动配置 vs 主辅联动任务（易混淆）

| | **主辅联动配置** | **主辅联动任务** |
| --- | --- | --- |
| **是什么** | 静态映射规则：监控索引号绑定哪些巡视点位、是否绑全景摄像机、是否启用 | 一次实际执行的巡视计划，由正向联动触发后自动生成 |
| **落在哪** | 联动配置页（`LinkageConfig`） | 任务管理列表；任务来源多为「智能联动任务」（`taskSource = 4`） |
| **谁维护** | 运维在联动配置中编辑点位、启用/禁用、绑定结束信号 | 系统生成；名称含「主辅联动任务」时禁止编辑、禁止启停开关 |
| **生命周期** | 长期有效，直到禁用或删除 | 随信号触发产生，执行完进入任务执行记录 / 巡视详情 |
| **关键标识** | `monitoringIndexnumber`（监控索引号）+ `stationId` | `planName` 含「主辅联动任务」、`planId` |
| **一句话** | 「哪个信号来了该看哪些点」 | 「这次信号来了，已经派出巡视」 |

关联关系：配置是任务的模板。配置未启用或未绑定点位时，信号变化不会形成有效巡视任务。

### 相邻概念（避免混用）

| 名称 | 是否等于主辅联动 | 说明 |
| --- | --- | --- |
| 主辅融合 | 否 | 字典 `MixAuxiliaryPlan` 开启后，巡视点位配置用「主辅融合」Tab 把巡视点位与主辅测点绑定，属于数据融合，不是任务联动 |
| 主辅位置状态告警 | 否 | 告警阈值中的位置一致性告警（返回值 ≠ 初始 0/1 时告警） |
| 主辅接入 | 否 | 首页统计在线监测 / SCADA 接入有效数、无效数 |
| 一体化告警联动（9_4） | 相近但独立 | 一体化数字站测点告警触发巡视，通知标签为「一体化告警联动」 |
| 主设备告警联动（9_8） | 相近但独立 | 特高压主设备告警触发，通知标签为「主设备告警联动」 |
| 一键顺控 | 部分复用联动字段 | 顺控推送会带监控索引号、联动信号；顺控执行只走点位默认摄像机终端 |
| 系统联动任务配置 | 开关级 | 字典 `IntegrationConfig.IntegrationEnable`，提示开启后任务量可能剧增 |

## 落地应用功能清单

### 配置监控索引号与巡视点位的映射

- **场景：**某断路器遥信变位时，自动拍摄对应套管、机构箱点位。
- **输入：**变电站、联动配置记录、巡检点位多选、可选全景摄像机、启用标志、备注。
- **结果：**`LinkageConfig/Save` 保存；后续该监控索引号变化即按点位列表启动巡视。

### 启用 / 禁用单条联动配置

- **场景：**检修期间临时关闭某间隔联动，避免误触发。
- **输入：**点击「禁用/启用」列，`IsEnable` 取反。
- **结果：**禁用后信号变化不再生成有效联动任务；配置仍保留。

### 遥控结束信号绑定（非区域）

- **场景：**遥控是过程量，需明确「结束」测点，否则任务无法收口。
- **输入：**源监控索引号 + 目标结束信号索引号。
- **结果：**`BindSignal` / `UnBindSignal`；列表用勾选标记当前结束信号。

### 正向联动：信号触发巡视任务

- **场景：**主辅监控遥信变位/遥测越限。
- **输入：**已启用配置 + 实时信号。
- **结果：**生成「主辅联动任务」；任务来源「智能联动任务」；按多终端策略执行；通知 9_6 推入「智能联动」；9_5 刷新配置表属性/值描述/时标；首页联动记录增加一行。

### 反向联动：生成回传文件

- **场景：**将巡视侧状态或指令回写主辅监控。
- **输入：**勾选配置（须带 `stationId`）+ 字典 `GenerateLinkageCommandConfig` 中的指令类型。
- **结果：**`GenerateReturnlinkageFile`；成功提示「反向联动文件生成成功」。边缘节点不展示该按钮。

### 区域层配置文件下发

- **场景：**区域配置好后同步到边缘执行。
- **输入：**单条行内「下发」，或勾选后顶部「联动配置文件下发」。
- **结果：**`LinkageFileDistribute`；边缘按最新映射执行正向联动。

### 查询联动历史

- **场景：**核对某监控索引号历史上是否联动过、当时值是什么。
- **输入：**`stationId` + `monitoringIndexnumber`。
- **结果：**历史列表（设备、索引号、类型、是否联动信号、属性、值描述、事件时标）。

### 实时通知与视频复核

- **场景：**值班员收到联动后立刻看现场。
- **输入：**WebSocket Type 9。
- **结果：**通知列表最多展示 50 条；详情弹出摄像机实况（1/4/9 宫格）；可跳转该次巡视详情。
- **代码事实：**`9_5` 写入通知栏的逻辑已注释，当前只刷新联动配置表；通知栏主辅任务以 `9_6` 为主。

### 任务管理对联动任务的保护

- **场景：**避免人工改掉系统生成的联动计划。
- **输入：**`planName` 包含「主辅联动任务」。
- **结果：**不可编辑、不可点启用开关；查看/立即执行/终止仍按普通任务权限与状态控制。

### 巡视点位与主辅测点绑定（主辅融合 / 在线监测）

- **场景：**巡视识别结果要和 SCADA/在线监测同一设备对比。
- **输入：**左侧点位树选点 + 右侧测点勾选绑定。
- **结果：**点位关联主辅信号（终端类型码 16）；重复绑定时提示覆盖；阿克苏下在线监测与 SCADA 互斥。

### 主辅位置状态告警

- **场景：**刀闸巡视位置与主辅遥信不一致。
- **输入：**初始位置 0 或 1、是否启用。
- **结果：**主辅返回值 ≠ 初始位置时产生告警（`alarmTabIndex = 8`）。

### 首页主辅接入统计（部分站点）

- **场景：**运维查看主辅测点接入是否有效。
- **输入：**无（概览统计）。
- **结果：**在线监测 / SCADA 总数、有效、无效；点击打开点位分库过滤。

### 一体化 / 特高压告警联动

- **场景：**一体化测点或特高压主设备告警时联动摄像机。
- **输入：**测点与系统点位绑定（上限 9）；或模拟告警。
- **结果：**通知 9_4 / 9_8，标签分别为「一体化告警联动」「主设备告警联动」；可与主辅联动任务同列展示。

### 一键顺控复用联动信息

- **场景：**顺控操作需要视频双确认。
- **输入：**顺控推送 9_1，附带 `linkage.MonitoringIndexnumber` 等。
- **结果：**通知展示监控索引号与联动信号；执行时**只跑默认摄像机终端**，不走多终端策略。

### 任务优先级中的「主辅设备联动」

- **场景：**联动任务与日常巡视抢终端。
- **输入：**任务优先级设置页的执行优先级（1–10）。
- **结果：**系统按优先级调度；「主辅设备联动」在部分枚举中禁用，表示该项由系统预置，不作为用户可选任务类型手工新建。

## 知识点小记

### 业务核心（三句话）

1. **配置**回答「哪个监控点对应哪些巡视点」；**任务**回答「这次信号已经派出巡视」。
2. **正向**是监控驱动巡视（自动、实时）；**反向**是巡视回写监控（文件、人工点按钮）。
3. **监控索引号**是主辅两侧的共同主键，配置、历史、下发、通知都围着它转。

### 一张对照表

```
主辅监控测点 (监控索引号)
        │
        ├─ 联动配置（启用？绑了哪些点位？遥控有无结束信号？）
        │         │ 正向触发
        │         ▼
        │   主辅联动任务 ──► 摄像机/机器人/无人机（多终端策略）
        │         │
        │         ▼
        │   智能联动通知 / 首页记录 / 巡视详情
        │
        └─ 反向联动文件 ◄── 人工「生成反向联动文件」+ 指令类型
                  │
                  └─ 区域「下发」► 边缘节点
```

### 易错点

| 易错 | 正确理解 |
| --- | --- |
| 把「联动配置」当成任务列表 | 配置是规则；任务在「任务管理」，名称带「主辅联动任务」 |
| 把「联动配置文件下发」当成反向联动 | 下发是区域 → 边缘同步**配置**；反向是 **GenerateReturnlinkageFile** |
| 开关拨一下就会改启用状态 | 开关被拦住；必须点「禁用/启用」**整列**，走 `IsEnable` 接口 |
| 在任务管理里改联动任务 | 名称含「主辅联动任务」则编辑、启停均被前端拦截 |
| 正向 / 反向搞反 | 正向：监控 → 巡视；反向：巡视 → 监控（代码只写了「反向」） |
| 主辅融合 = 主辅联动 | 融合是点位与测点绑定；联动是信号驱动任务 |
| 一体化联动 = 主辅联动 | 通知类型不同（9_4 vs 9_6），绑定入口也不同 |
| 顺控和联动执行策略一样 | 顺控只用默认摄像机；联动走多终端策略 |
| 区域层打开联动配置没有数据 | `request-auto="!isRegion"`，必须先选变电站 |
| 边缘节点找「生成反向联动文件」 | `!isEdge` 才显示 |
| 9_5 会弹智能联动通知 | 通知写入已注释，9_5 只刷新配置表；弹通知的是 9_6 |

### 新人上手顺序

1. 在联动配置中选站，认监控索引号、遥信/遥控、启用状态。
2. 编辑一条配置，看绑定了哪些巡视点位。
3. 对照任务管理里名称含「主辅联动任务」的记录，理解配置 → 任务。
4. 区分顶部「生成反向联动文件」与「联动配置文件下发」。
5. 用一次实时通知（智能联动）走到巡视详情，走通正向闭环。
6. 再看点位配置的「在线监测 / 主辅融合」，不要和联动配置页搞混。

## 总结

主辅联动的本质，是主辅设备监控系统与智能巡视系统之间的双向协同：**正向**由监控测点变化驱动巡视取证，**反向**由巡视侧生成文件回写监控。落地时务必分清三层对象——

1. **联动配置**：规则层，以监控索引号为键，绑定巡视点位并控制启用；
2. **主辅联动任务**：执行层，由正向触发自动生成，任务管理中不可编辑/启停；
3. **点位主辅融合 / 位置告警等**：数据关联与告警能力，名称相近但不是「信号 → 任务」这条主链路。

区域层侧重配置下发到边缘；边缘/单站侧重执行与结束信号；开发与运维排障时优先核对「配置是否启用 → 点位是否绑定 → 正向任务是否生成 → 反向文件是否按指令生成」。
